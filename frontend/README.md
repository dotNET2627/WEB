# DentalManagement Frontend

This folder contains the Next.js App Router frontend for DentalManagement.

Package installation is intentionally left to the project owner. Add the base Next.js, React, TypeScript, ESLint, Tailwind CSS and PostCSS dependencies, then run `npm.cmd install` from this folder on Windows.

Copy `.env.example` to `.env.local` before running the development server. The backend development URL is `http://localhost:5260` by default.
